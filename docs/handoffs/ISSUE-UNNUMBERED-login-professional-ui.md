- **بازبینی مستقل (سطح: Diff UI روی فرم احراز هویت؛ بدون تغییر منطق):**
  - `security-reviewer`: یافته‌ای نداشت. خودش اعلام کرد سرور و مرورگر را اجرا نکرده و CSS را فقط با جست‌وجوی الگوهای پرخطر دیده است. مصرف توکن: ۳۵٬۷۵۵ (عدد گزارش ابزار).
  - `code-reviewer`: یک یافتهٔ متوسط و چند یافتهٔ کم. مصرف توکن: ۶۳٬۳۶۸ (عدد گزارش ابزار). آن را مستقیماً راستی‌آزمایی کردم:
    - صفحهٔ `LoginSuccess` در LTR وسط‌چین نبود: درست بود و اصلاح شد. شاهد: مرکز کارت ۷۲۰ از ۷۲۰ در هر دو جهت.
    - هدف لمسی دکمهٔ رمز ۴۰px بود: درست بود و ۴۴px شد.
    - قاعدهٔ ارتفاع نمودار روی صفحهٔ کوتاه می‌توانست letterbox ایجاد کند: درست بود و قاعدهٔ غیرضروری حذف شد.

- ارزیابی: تقسیم کار به دو بازبین و پیاده‌ساز یکی (Lead) صرفه داشت؛ حدود ۹۹ هزار توکن برای دو بازبین مصرف شد و یک خطای واقعی (LTR در LoginSuccess) پیدا کرد.
