# تحویل — بازچینی منوی مدیریت سیستم و غیرفعال‌سازی موقت بخش‌ها

## درخواست مالک
- «مجوزهای دسترسی» باید از بخش «دسترسی و مجوزها» خارج و مستقیماً بعد از «مدیریت کاربران» قرار بگیرد.
- بخش «دسترسی و مجوزها» به انتهای زیرمنوهای مدیریت سیستم منتقل و کاملاً غیرفعال شود.
- بخش «کارکنان» نیز مطابق تصمیم قبلی غیرفعال باقی بماند.

## وضعیت نهایی ناوبری
1. مدیریت کاربران — فعال
2. مجوزهای دسترسی — فعال؛ مسیر `/admin/access`
3. ساختار سازمانی — فعال؛ شامل واحدهای سازمانی و سمت‌های سازمانی
4. شرکت‌ها و عضویت‌ها — مطابق دسترسی‌های فعلی
5. سوابق امنیتی و مدیریتی — مطابق دسترسی‌های فعلی
6. کارکنان — غیرفعال و با نشانگر «به‌زودی»
7. دسترسی و مجوزها — غیرفعال و آخرین بخش؛ زیرگزینه‌های گروه‌های دسترسی و کاتالوگ/جزئیات مجوزها نمایش داده نمی‌شوند.

## مرز تغییر
- فقط ناوبری UI، تست‌های Sidebar و این handoff تغییر می‌کنند.
- مسیر `/admin/access` همان مسیر موجود است و صرفاً محل نمایش لینک آن در منو عوض شده است.
- Routeها، APIها، permission catalog، داده‌ها، migrationها و authorization سمت سرور تغییر نمی‌کنند.
- غیرفعال بودن بخش آخر فقط وضعیت UI است و جایگزین کنترل دسترسی backend یا route guard نیست.

## آزمون و اعتبارسنجی
- تست‌ها ترتیب «مدیریت کاربران» سپس «مجوزهای دسترسی» را بررسی می‌کنند.
- تست‌ها غیرفعال بودن کامل بخش «دسترسی و مجوزها» و قرار گرفتن آن در انتهای منو را بررسی می‌کنند.
- تست‌ها غیرفعال ماندن «کارکنان» را حفظ می‌کنند.
- تست محلی، typecheck، build و بازبینی بصری در این محیط اجرا نشده‌اند؛ CI باید نتیجه را تأیید کند.
- هیچ Merge انجام نشده است.

## بازگشت
برای بازگردانی، PR را revert کنید؛ هیچ تغییر داده یا migration وجود ندارد.
