# تحویل — بازچینی منوی مدیریت سیستم و غیرفعال‌سازی موقت بخش‌ها

## درخواست و محدوده
درخواست مالک در 2026-11-09:
- ترتیب اولیه: مدیریت کاربران، مجوزهای دسترسی، ساختار سازمانی، سایر بخش‌ها.
- «کارکنان» فعلاً غیرفعال و در انتهای منوی «مدیریت سیستم» قرار بگیرد.
- در اصلاح بعدی، مالک صریحاً فعال‌سازی «دسترسی و مجوزها» را درخواست کرد.

## تغییر پیاده‌سازی
- ترتیب منو: مدیریت کاربران، دسترسی و مجوزها، ساختار سازمانی، شرکت‌ها و عضویت‌ها، سوابق امنیتی و مدیریتی، کارکنان.
- «دسترسی و مجوزها» فعال است و شامل لینک‌های واقعی «گروه‌های دسترسی» (/admin/roles)، «کاتالوگ و جزئیات مجوزها» (/admin/permissions) و «مجوزهای دسترسی» (/admin/access) است.
- نمایش لینک‌ها همچنان بر اساس permission hintهای موجود انجام می‌شود؛ route guard و مجوز سمت سرور مرجع نهایی هستند.
- «ساختار سازمانی» شامل «واحدهای سازمانی» و «سمت‌های سازمانی» است.
- «کارکنان» در انتهای منو مستقل و disabled باقی می‌ماند و با نشانگر «به‌زودی» نمایش داده می‌شود.

## مرزهای ایمنی
- فقط ناوبری UI تغییر کرده است.
- Routeها، APIها، permission catalog، داده‌ها، migrationها و authorization سمت سرور حذف یا تغییر نکرده‌اند.
- دسترسی مستقیم به URLها عمداً با این PR مسدود نمی‌شود؛ کنترل واقعی همچنان در API و route guardهای موجود است. این تصمیم به معنی غیرفعال‌سازی امنیتی backend نیست.

## آزمون و اعتبارسنجی
- تست‌های Sidebar برای لینک‌های دسترسی، ترتیب منو، فیلتر مجوزها و باقی‌ماندن «کارکنان» در وضعیت disabled به‌روزرسانی شده‌اند.
- تست محلی، typecheck و build در این محیط اجرا نشده‌اند؛ CI باید نتیجه را تأیید کند.
- بازبینی بصری مرورگر نیز هنوز انجام نشده است.

## بازگشت
برای بازگردانی، PR را revert کنید؛ هیچ تغییر داده یا migration وجود ندارد.
