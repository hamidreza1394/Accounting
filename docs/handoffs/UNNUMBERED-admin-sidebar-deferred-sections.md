# تحویل — بازچینی منوی مدیریت سیستم و غیرفعال‌سازی موقت بخش‌ها

## درخواست و محدوده
درخواست مالک در 2026-11-09:
- «ساختار سازمانی» بالاتر از «دسترسی و مجوزها» قرار بگیرد.
- «دسترسی و مجوزها» تا تصمیم بعدی غیرفعال باشد.
- «کارکنان» نیز فعلاً غیرفعال شود.
- دو بخش غیرفعال در پایین منوی «مدیریت سیستم» قرار بگیرند.

## تغییر پیاده‌سازی
- ترتیب منو: مدیریت کاربران، ساختار سازمانی، شرکت‌ها و عضویت‌ها، سوابق امنیتی و مدیریتی، دسترسی و مجوزها، کارکنان.
- «ساختار سازمانی» فقط شامل «واحدهای سازمانی» و «سمت‌های سازمانی» است.
- «دسترسی و مجوزها» شامل گروه‌های دسترسی، کاتالوگ/جزئیات مجوزها و مجوزهای دسترسی است؛ تمام leafها فاقد route و با وضعیت disabled نمایش داده می‌شوند.
- «کارکنان» به یک بخش مستقل در انتهای منو منتقل شده و leaf آن فاقد route و disabled است.
- نشانگر موجود «به‌زودی» و aria-disabled استفاده می‌شود؛ هیچ لینک/دکمه قابل کلیک برای این موارد render نمی‌شود.

## مرزهای ایمنی
- فقط ناوبری UI تغییر کرده است.
- Routeها، APIها، permission catalog، داده‌ها، migrationها و authorization سمت سرور حذف یا تغییر نکرده‌اند.
- دسترسی مستقیم به URLها عمداً با این PR مسدود نمی‌شود؛ کنترل واقعی همچنان در API و route guardهای موجود است. این تصمیم به معنی غیرفعال‌سازی امنیتی backend نیست.

## آزمون و اعتبارسنجی
- تست‌های Sidebar برای ترتیب جدید، وضعیت غیرقابل کلیک و جایگاه انتهایی بخش‌ها اصلاح شده‌اند.
- تست محلی، typecheck و build در این محیط اجرا نشده‌اند؛ CI باید نتیجه را تأیید کند.
- بازبینی بصری مرورگر نیز هنوز انجام نشده است.

## بازگشت
برای بازگردانی، PR را revert کنید؛ هیچ تغییر داده یا migration وجود ندارد.
