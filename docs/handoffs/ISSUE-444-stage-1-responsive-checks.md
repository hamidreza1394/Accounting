## اجرای واقعی مرورگر در 2026-11-08 — اجرا نشد (گزارش صریح)

- **اجرا نشد و ادعایی انجام نشده است.** تلاش واقعی برای برپا کردن پشتهٔ E2E انجام شد و با محدودیت‌های سخت Sandbox مسدود ماند:
  1. بدون Docker و بدون sudo کارآمد (`sudo` رمز می‌خواهد)؛ سیاست‌های Sandbox اجازه `mount`/bind-mount حتی در user namespace را نمی‌دهند.
  2. نصب rootless SQL Server 2022 (استخراج بستهٔ رسمی مایکروسافت در home + اجرا با `LD_PRELOAD` برای بازنویسی مسیر `/var/opt/mssql`) تا سه بار تلاش شد؛ موتور در گام ساخت `.system` از syscall مستقیم خارج از libc استفاده می‌کند و مسدودی آن با shim قابل رفع نبود (شواهد: `/tmp/sqlservr-console.log`، شیم `/home/z/my-project/scripts/mssqlpath.c`).
  3. فونت اثر: E2E کامل (Playwright + axe روی سرور واقعی) همچنان در CI مخزن اجرا می‌شود و آخرین اجرای سبز آن برای SHAهای Stage 1 در Handoff اصلی ثبت است.
- در نتیجه، «تست مرورگری امروز» جایگزین شواهد واقعی 2026-11-07 نشده و نشده است؛ فقط موارد قابل‌اجرای محلی (تست کامپوننتی/build/offline) تازه اجرا شدند و یک WARN معلق بسته شد.
