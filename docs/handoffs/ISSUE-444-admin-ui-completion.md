## 4. کارهای باقی‌مانده از دامنه #444

1. **E2E واقعی مدیریت نقش و کاربران:** یک سناریوی منفی واقعی برای کاربر عادی به `tests/e2e/specs/faranou.spec.mjs` افزوده شده است: رد مسیر React، عدم ارسال درخواست admin از UI، پاسخ 403 برای API کاتالوگ و فهرست نقش‌ها و پاسخ 401 برای کاربر ناشناس. CI آن در PR بعدی هنوز باید سبز شود. سناریوهای مثبت مدیر نصب (ایجاد/ویرایش/بازخوانی نقش)، نقش سیستمی read-only، Anti-forgery و concurrency همچنان باقی‌اند.
2. **Delegation Ceiling و مدیر شرکتی:** APIهای #459 فعلاً فقط Installation Administrator را مجاز می‌کنند. پیش از افزودن Company Manager باید سقف تفویض تعریف و سمت سرور enforce شود؛ مدیر نتواند مجوزی فراتر از اختیار مؤثر خود اعطا کند. این مورد با UI-only fix حل نمی‌شود.
3. **اعضای نقش:** API فهرست اعضا و گردش انتقال اعضا بین نقش‌ها وجود ندارد. غیرفعال‌سازی نقش دارای عضو فعال فعلاً با 409 رد می‌شود.
4. **درخواست عضویت مقصد:** PR #479 در شاخه مستقل Backend در حال تکمیل است؛ این PR مستنداتی فایل‌ها یا شاخه #479 را تغییر نمی‌دهد. پس از تأیید CI، UI درخواست و تصمیم approve/reject باید با Issue مستقل انجام شود.
5. **S2 ساختار سازمانی:** سمت/واحد سازمانی، مدیر مستقیم و اتصال به Employee/Payroll هنوز طراحی/پیاده‌سازی نشده‌اند؛ سمت شغلی نباید با CompanyRole امنیتی یکی شود.
6. **S5 پوشش کامل enforcement:** inventory endpointها و آزمون‌های منفی tenant/permission باید تکمیل شود؛ پنهان‌سازی UI هرگز مرجع امنیت نیست.
7. **S6 entitlement:** مجوز عملیاتی کاربر و entitlement تجاری مستقل‌اند؛ اتصال entitlement مؤثر به مجوزدهنده همچنان خارج از برش UI و نیازمند قرارداد معتبر است.
8. **S7 گزارش امنیت مدیریتی:** گزارش سراسری ورود/خروج، تغییرات دسترسی، چرخه عمر نشست و retention هنوز کامل نیست. Login history خودکار کاربر جایگزین Audit مدیریتی نیست.
9. **Accessibility:** axe و صفحه‌خوان برای صفحات مدیریت اجرا نشده‌اند.
