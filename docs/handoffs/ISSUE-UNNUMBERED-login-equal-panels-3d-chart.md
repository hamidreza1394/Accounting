## امنیت، داده و سازگاری
- PageModel، احراز هویت، anti-forgery، `ReturnUrl`، کوکی‌ها و مجوزها دست‌نخورده‌اند؛ Migration و Schema ندارد.
- CSP (`style-src 'self'`, `img-src 'self' data:`, `font-src 'self'`) رعایت شد: بدون style attribute، بدون `<style>`، بدون اسکریپت درون‌خطی، تصویر پس‌زمینه از `/images`.
- ویژگی‌های CSS مانند `backdrop-filter`، `mask-image` و `filter: blur` در مرورگرهای قدیمی ممکن است نباشند؛ در این حالت صفحه با کارت تیره و بدون محو شدن شبکه نمایش داده می‌شود و خوانایی حفظ می‌شود.
