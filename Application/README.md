# Application Layer (scaffold)

این پروژه مرز آینده Use Caseهای برنامه است. در این لایه باید جریان‌های کاربردی، DTOها، قراردادهای لازم و اعتبارسنجی کاربردی قرار بگیرند. وابستگی مجاز فعلی به `Domain` است.

فعلاً منطق موجود از PageModelها به این پروژه منتقل نشده، چون پیش از انتقال باید رفتارهای موجود با تست پوشش داده شوند. هر انتقال باید در PR مستقل، همراه تست و بدون وابستگی Application به Razor Pages، EF Core یا پیاده‌سازی SQL انجام شود.
